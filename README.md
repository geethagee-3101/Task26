# TASK 26 – TEXT CLEANING BASICS

## Project Overview
This task focuses on cleaning and standardizing customer data by removing unwanted spaces, correcting capitalization, and maintaining consistent text formats using Excel and Python.

## Tools Used
- Microsoft Excel
- Python

## Dataset
Customer Dataset containing 12 sample records.

### Columns
- Customer ID
- Customer Name
- City
- Email
- Customer Segment

## Cleaning Operations Performed
1. Removed leading and trailing spaces using TRIM.
2. Removed repeated spaces between words.
3. Standardized customer names using PROPER.
4. Corrected city name capitalization.
5. Converted email addresses to lowercase using LOWER.
6. Standardized customer segment names.

## Excel Functions Used
- TRIM()
- PROPER()
- LOWER()

## Python Methods Used
- strip()
- split()
- join()
- title()
- lower()

## Deliverables
- Raw customer dataset.
- Cleaned customer dataset.
- Before-and-after examples.
- Cleaning log.

## Learning Outcomes
- Learned basic text-cleaning techniques.
- Understood how to remove unwanted spaces.
- Practiced text functions in Excel.
- Improved data consistency and quality.
- Gained practical experience with Python text processing.

## Conclusion
Successfully cleaned and standardized 12 customer records using Excel and Python. This task helped improve data quality, consistency, and readability.
